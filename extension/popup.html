ALGOTRACK CONNECT

LeetCode sync

When a problem page shows an accepted result, open AlgoTrack and add it to your log.

Use your local AlgoTrack page URL (for example, a local VS Code Live Server URL or a file:/// URL). Avoid a hosted URL if you want your progress to stay on this device.

No LeetCode username, password, session cookie, or account data is collected. Only the accepted problem title and URL are sent to your configured AlgoTrack page.
